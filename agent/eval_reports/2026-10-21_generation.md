# Generation 평가: 긴 조문 관련 항 고르기 전후 (2026-10-21)

Generation 평가 스크립트(`scripts/eval_generation.py`)를 추가하고, 긴 조문을 앞에서부터 자르던 방식을 관련 항을 고르는 방식으로 바꾼 전후를 비교한 기록입니다.
입력은 `shared/fixtures/routing` 11개(실제 MCP 결과), 정답은 `eval_data/generation_gold.json`입니다.

## 고친 문제

근거 하나를 3,000자에서 앞부터 잘라서, 긴 조문의 뒤쪽 항이 모델에게 전달되지 않았습니다.

- 05 "SUP-0003에 단가 12,000원, 결제 75일, 연동 없이 제안해도 돼?"에서 `check_offer`가 "원재료 비용이 하도급대금의 10% 이상이면 연동 사항을 서면에 적어야 한다"의 근거로 하도급법 제2조를 겁니다.
- 제2조는 4,162자이고, 그 근거인 "주요 원재료" 정의(그 비용이 하도급대금의 100분의 10 이상인 원재료)는 16번째 항이라 잘려 나갔습니다.
- 그래서 모델은 10% 기준의 조문 근거 없이 설명해야 했습니다.

이제 3,000자(`law_article`은 6,000자)를 넘는 조문은 하위 질문, 같은 조문의 검색 결과, 그 조문을 건 검사 항목 문구와 겹치는 글자 쌍이 많은 항부터 넣고, 생략한 항 번호를 본문 끝에 적습니다.

## 모델 호출 없는 지표 (`--offline`)

```bash
uv run python scripts/eval_generation.py --offline
```

| 근거 포함 (정답에 필요한 문구가 근거에 있음) | 92% (12/13) | **100% (13/13)** |
| 프롬프트 크기 평균 | 5,231자 | 5,238자 |
| 프롬프트 크기 최대 (03) | 11,302자 | 11,302자 |
| 05 제2조 근거에 "주요 원재료" 정의 | 없음 | 있음 |

3,000자 이하 조문은 전과 같이 통째로 들어가서 다른 fixture의 근거는 바뀌지 않았습니다.

## 다음에 볼 것

- 정답 포인트는 개발용 fixture 8개뿐입니다. 분해 검증 세트(24개)처럼 Generation도 별도 검증 질문을 만들어야 한 두 건 차이를 믿을 수 있습니다. 검증 질문은 Routing 결과가 필요하므로 `route_fixtures.py`로 실제 MCP 결과를 저장해 만듭니다.
- 채점 모델(gpt-4.1-mini)이 생성 모델과 같아 점수가 후하게 나올 수 있습니다. 중요한 비교는 다른 모델로 한 번 더 채점합니다.
- 03·04·05는 프롬프트가 9천~1만1천 자입니다. 대부분 조문 전문입니다. 근거 양을 줄이면 속도와 비용이 줄지만, 이번 측정에서 관련도 기준으로 더 잘라 보니 필요한 항(예: 제2조 ③ 수급사업자 정의)이 빠졌습니다. 줄이려면 정답 포인트 커버율로 확인하면서 합니다.
