- 개발 답변 종류 불일치 3건은 무의미한 입력을 failed 대신 clarify로 처리한 경우다. 점수를 바꾸려고 정답을 수정하지 않았다.
- 검증 평균 7.84초에는 89.39초 요청 1건이 포함된다. 그 요청의 분해 단계는 86.33초였다. API 내부 대기·재시도 중 무엇이 원인인지는 현재 기록만으로 확정할 수 없다.
- 검증에서 분해 형식 오류 재시도 1건이 있었고 해당 요청은 11.29초였다. 분해 LLM 호출은 37회, 생성은 36회다. 표의 재생성은 Generation 재작성만 뜻한다.
- 근거 없는 주장 수는 LLM 채점 경고이며 확정 오류 수가 아니다. 개발 기업 비교의 인증 보유 여부 문장 1건은 실제 evidence의 iatf16949/iso14001 값과 일치하는 오탐을 확인했다.
- 개발 감사등급 B 누락은 3회 중 2회였다. 단일 예비 평가에서 3/3 누락됐던 현상과도 흔들림이 있다.

- 같은 생성·채점 모델과 작은 질문 집합의 반복 결과다. 독립 정답률이나 운영 성공률로 일반화하지 않는다.
