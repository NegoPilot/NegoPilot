# 회원과 개인 대화 연결 검증

검증일은 2026년 10월 21일이다. 기존 DB와 기존 서버를 보존하고 별도 로컬 PostgreSQL DB 및 포트에서 실행했다. 실행 방법은 [개발 시작 가이드](../GETTING_STARTED.md)를 따른다.

## 검증 환경

| 구성 | 사용한 환경 |
| --- | --- |
| 프런트 | Vue 개발 서버 5176 |
| 백엔드 | Java 21과 Spring 8082 |
| Agent | Python 내부 API 9202와 `live` 모드 |
| 모델 | Ollama 0.32.5의 `qwen3:8b`. 분해와 최종 생성 모두 실제 모델 호출 |
| 도구 | business-mcp 9105와 law-mcp 9104 |
| 저장소 | 회원과 세션 및 대화용 PostgreSQL. 업무 DB는 별도로 구성 |

Agent는 클라우드 호출 실패를 stub으로 바꾸지 않는다. 이 검증에서는 로컬 모델 공급자를 명시적으로 선택했다. Ollama의 구조화 출력이 정규식 `\d`를 받지 못해 실패하는 문제는 전송할 JSON Schema의 표현을 `[0-9]`로 변환해 해결했다. 응답의 원래 Pydantic 검증은 유지한다.

`live`는 모델과 도구를 실제로 실행했다는 의미다. 데이터 전체가 실자료라는 뜻은 아니다. 실습 업무 DB는 저장소의 DART 기업 30개와 가상 기업 120개를 적재했다. DART 기업에도 인증과 생산능력 및 품질과 계약 및 견적의 가상 자료가 포함돼 있다. 화면은 항목별 출처를 표시한다. 기존 운영 DB를 초기화하지 않았다.

## 실제 브라우저에서 확인한 흐름

승인된 USER 계정으로 기업 선택 없이 질문했다.

| 입력 | 관찰한 결과 |
| --- | --- |
| 부산 협력사 찾아줘 | 실제 business-mcp 조회 후 협력사 이름과 근거 링크를 표시했다. 응답은 `live`와 `COMPLETED`였다. |
| SNT모티브 기업 정보를 알려줘 | `find_suppliers`로 이름을 찾은 뒤 `get_supplier(SUP-0009)`를 실행했다. 실제 모델이 기업 정보와 근거를 생성했다. |
| 이 회사의 재무 상태는? | 앞 질문의 기업을 이어받아 같은 `SUP-0009`를 조회했다. DB의 2023년부터 2025년까지 재무 자료를 사용한 답변을 표시했다. |
| 같은 대화 주소 새로고침 | 두 질문과 두 답변 및 근거 링크가 DB에서 복원됐다. |

모델이 만든 문장의 정확도를 모든 질문에 대해 보증하는 검증은 아니다. 예를 들어 재무 후속 답변에서 DB에 부채 비율이 있어도 모델이 `확인 필요`라고 출력했다. 호출과 저장의 성공 여부를 답변 품질과 구분했다.

## 실제 프로세스와 DB 통합 검사

별도 테스트 DB에서 15개 항목을 확인했다. 이 단계의 채팅 생성은 stub을 사용했다. 실제 모델 검증은 위 브라우저 검사와 구분한다.

- 회원 가입 후 PENDING 상태에서는 업무 API 접근이 제한됐다. 관리자 승인 후 기존 로그인 세션에도 ACTIVE 상태가 반영됐다.
- 로그인과 로그아웃 및 접근 이력이 기록됐다. 로그아웃은 204를 반환했고 이후 인증 요청은 401을 반환했다.
- 질문과 답변이 함께 저장됐다. 다른 USER와 ADMIN이 타인의 대화 및 저장 응답을 요청한 6개 경로는 404를 반환했다.
- 수동 협력사를 등록한 뒤 MCP에서 조회했다. 비활성화 후 일반 조회에서 제외됐다.
- 법령 6개와 버전 35개를 조회했다. 실제 외부 수집 작업이 SUCCEEDED로 끝나고 수집 시각이 반영됐다.
- Spring을 재시작한 뒤 로그인 세션과 대화 응답 JSON이 유지됐다.

## 제공 범위

회원 가입과 로그인 및 개인 대화 화면은 서버와 연결된다. 관리자 회원 및 협력사 API와 법령 버전 및 최신화 API는 구현됐다. 관리자 화면의 실제 버튼 연결은 후속 작업이다. 별도 협력사 검색 화면도 연결 준비 안내를 표시한다. 법령 수동 등록 API는 제공하지 않는다.

기본 공개 API는 인증과 DB 저장을 사용한다. 기존 메모리 대화와 fixture 계약은 `legacy-test`에서만 회귀 검증하며 일반 서비스 실행에 사용하지 않는다.
