AI 정량 지표 17개는 판정이 아닌 측정값이라 따로 센다: 이번 실험으로 측정 9개, 기존 보고서 값 1개, 미측정 7개.

**잘 되는 것**
- 회원·권한·보안: 가입 → 승인 대기 → 관리자 승인 → 사용, 정지 즉시 반영, 대화 격리, CSRF, 오류 응답의 내부 정보 숨김까지 E2E로 모두 통과
- 대화: 이어지는 질문의 맥락 반영, 새로고침·링크 복원, 근거 상세 새 탭, 중복 전송 차단
- 장애 대응: business-mcp를 끈 상태에서 혼합 질문을 하면 되는 부분은 답하고 안 되는 부분은 안내

**질문 유형별 평가 (3-3) 한 줄 요약:** 리트리브는 4개 유형 모두 정확했다 (다중 기업 식별, 조건 검색, 유사 이름, multi-hop 연결). 약점은 리트리브 뒤에 있다: **도구 근거로 답한 답변의 29%(4/14)에 인용이 없고**, multi-hop 협상안 질문이 **7회 중 2회 실패**(분해 실패 1, 서버 500 1)했으며, 거래 지속 여부를 묻는 판단 질문에서 **데이터와 반대로 "양호"라고 판단**했다.

**릴리스 전에 꼭 볼 것 (높음)**

1. **법률 답변 정확도 문제 4건.** #166 쉼표가 깨진 금액이 근거 검사 통과, #167 연동 10% 기준 조문 미검색, #168 감액 질문에서 제11조 미검색, **E2E-1 근거가 있는 법률 답변에 인용이 빠져 "근거 자료 없음"으로 표시됨** (대표 질문 "하도급법상 대금 지급 기한"에서 발생)
2. **되묻기 선택지가 루프를 돈다 (E2E-2).** "협상안 검사해줘" → 선택지를 누르면 "1"이 전송되고 같은 되묻기가 반복된다.
3. **관리자 기능이 화면에서 일부만 된다.** 회원 정지·권한 변경 화면이 없고(E2E-3), 데이터 관리·협력사 등록·법령 등록은 "연결 준비 중", 법규 검토는 정적 예시다.
4. **로그인 시도 횟수 제한이 없다.** 20회 연속 실패 후에도 맞는 비밀번호로 바로 로그인된다.

**체크리스트 문서 수정 필요:** 공개 API 경로에서 버전이 빠졌다 (#157). `/api/v1/admin/**` → `/api/admin/**`.
