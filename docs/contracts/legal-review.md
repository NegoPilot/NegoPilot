# 법규 검토 화면 API

`/review`는 로그인한 활성 회원이 기업 정보와 계약 조건을 입력해 검토하는 화면이다.
`POST /api/v2/legal-reviews` → Spring → `POST /internal/v2/legal-reviews` → Agent Router → business/law MCP 순서로 실행한다.
공개 API는 기존 세션·CSRF 정책을 적용하며 내부 API 키를 브라우저에 전달하지 않는다.

## 입력

공개 요청 본문은 `ReviewOffer` 객체다. 공급자 ID(`SUP-0001` 형식), RFQ ID(`RFQ-2026-001`), 제안 단가(양의 정수, 원), 지급기한(양의 정수, 일), 계약기간(양의 정수, 일), 연동 약정 포함 여부(boolean), 기준일(실제 ISO 날짜), `supplier_size`, `buyer_size`가 필수다. 등록된 공급자와 RFQ를 사용한다.

원재료 비중은 UI에서 0–100%, API에서는 0–1 또는 null이다. `linkage_waived_by_agreement`는 미연동 합의 여부다. 기업 정보 객체는 KSIC, 평균매출액·자산총액·관계기업 합산 매출액(억원), 독립성, 관계기업 유무, 좌석 제조업 여부, 유예·간주 해당 여부, 경과조치 검토 완료 여부, 관계기업 계산 검증 여부, 증빙 참조를 받는다.

모르는 수치와 판단은 null로 전달한다. 확인하지 않은 검토 완료 항목은 false다. 관계기업이 있다고 선택하지 않으면 숨겨진 합산 매출액과 검증 완료 값은 사용하지 않는다. 단위 변환은 원재료 비중에만 적용하며 억원 금액을 원으로 변환하지 않는다.

입력값을 자연어로 변환하거나 LLM으로 재추출하지 않는다. 구조화된 offer_check 1개와 별표 1·별표 3·연동 예외 자료 검색 3개를 생성하고 기존 Router로 실행한다. 최종 기업 규모 답변은 기존 결정적 렌더러로 작성하여 true/false/null 판정을 유지한다.

## 응답·화면

응답은 기존 generation schema 0.3이며 conversation_id와 response_id는 없다. 요청 ID, 실제 도구 인자·응답, 근거, 인용, 최종 답변을 포함한다. 기존 Spring generation 응답 검증을 재사용한다.

화면은 처리 중 중복 제출과 편집을 막고, 실패 시 다시 실행할 수 있다. 입력 변경 후 기존 결과에는 이전 입력 결과라는 경고를 표시한다. 제출 당시 입력과 근거 전문·원문 링크를 펼칠 수 있다. 답변 인용 번호는 근거 항목으로 연결한다. 결과는 별도 DB에 저장되지 않으며 페이지를 떠나면 사라진다.

## 검증 (2026-10-23)

합성 QA 입력: SUP-0034 / RFQ-2026-001, C30399, 공급자 매출 1100억원, 양사 자산 2000억원, 관계기업 없음, 경과조치 검토 완료, 유예·간주 아님, 증빙 SYNTHETIC-REVIEW-QA. 단가 3900원, 지급 60일, 계약 365일, 원재료 40%, 연동 미포함.

- 구매자 120억원·독립성 충족: 소기업 해당, 연동 소기업 예외 안내.
- 구매자 120.01억원·독립성 충족: 소기업 비해당, 연동 약정 누락 위험 안내.
- 구매자 독립성 모름: 판정 보류와 추가 확인 안내. 비해당으로 설명하지 않음.

실제 공개 API 3개 사례에서 입력 단위, null 보존, 규모 판정, 최종 문구, 별표 1·3, 표준 연동계약서 검색, 인용, 도구 오류 여부를 검증했다. 실제 웹 폼으로 같은 3개 상태를 검증했다. 로컬 증거는 gitignore된 `agent/eval_results/review-ui-2026-10-23/`에 둔다.

자동 검증: Agent 관련 147개, Spring 컨트롤러 인증·CSRF 및 응답 검증, 프런트 API 회귀 검사, 타입 검사와 Vite 빌드. 기존 미추적 `* 2.vue` 복사본의 타입 오류는 이번 변경과 무관하며 타입 검사 시 해당 복사본을 제외했다.

범위: 현재 규모 엔진이 지원하는 제조업·기준일 범위에 한한다. 자료 검색 성공과 규칙 검사 통과는 거래 전체의 적법성 보증이 아니다. 위탁 유형·원사업자 요건 등 기존 검사 범위 밖의 조건은 별도 확인한다.
